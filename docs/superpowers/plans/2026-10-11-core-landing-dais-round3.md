# The Core's Landing, Round 3 (the aurora slate casing) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Encase the dais and the cylinder cleared above it in **aurora slate**, a new block: deepslate with glowing
flecks of the aurora, animated exactly like aurora stone's veins. Keep the aurora stone roots inside the dais.

**Architecture:**
- **`LandingDais` (pure, tested):**
  - **Plan:** `Plan` becomes `(floor, blocks, shell, wall)`.
    - `shell` is every casing block at or below the floor.
    - `wall` is the columns cased above the floor, up to the sky.
    - The roots no longer leave the dais.
  - **Casing rule:** `fuses(...)` is a pure rule saying which existing block becomes aurora slate.
- **`RealmManager.buildDais`:** applies the shell and the wall. This replaces the old stone fluid seal: fluids in the
  wall are now sealed in aurora slate instead.
- **The block:** `aurora_slate` uses vanilla deepslate's textures with an emissive animated overlay of flecks. The
  overlay is generated by `tools/anchor/dais.mjs`, whose colours come from the same `auroraAt` function as aurora
  stone's veins.

**Tech Stack:** Java 21, Forge 1.21.11 (61.1.0), JUnit 5; Node (`node:test`).

**Spec:** `docs/superpowers/specs/2026-10-11-core-landing-dais-design.md`, section "The aurora slate casing (round 3)".

## Global Constraints

- **Writing:**
  - No em dashes, and no spaced en dash used in their place.
  - Commit messages without `Co-Authored-By`, written as one descriptive sentence.
- **Gradle:** never run Gradle while the dev server or client runs. Stop the background tasks `brlzq1k7s` (runServer)
  and `b25asz8o2` (runClient) first.
- **Aurora Slate:**
  - id `aurora_slate`, name "Aurora Slate";
  - strength 3 / 6, `SoundType.DEEPSLATE`, pickaxe, drops itself, no light of its own.
- **The flecks' look:**
  - **Colour:** each fleck is coloured by `auroraAt` (the veins' function), so the colours shift in step with the veins.
  - **Twinkle:** each fleck twinkles on a 4 s cycle.
  - **Animation strip:** the same 128 frames at `frametime` 5, interpolated.
  - **Glow:** the flecks have `light_emission` 15.
  - **Halo:** the halo pixels are mixed with deepslate grey (80, 80, 83).
- **What fuses into aurora slate:**
  - Solid blocks that are not leaves, have no block entity and are not unbreakable.
  - Fluids only in the wall above the floor.
- **Shape:** the casing lies within 6 blocks of the Core's column.

## Review Focus

1. **A chest or spawner inside the casing.** It stays untouched, contents and all: `fuses` refuses block entities
   (test in Task 1).
2. **Water under an ocean dais.** It stays water: fluids fuse only in the wall (test in Task 1). A lake or lava beside a
   hillside dais is sealed in the wall, so nothing pours in.
3. **Bedrock or unbreakable blocks in the casing.** They are never replaced (test in Task 1).
4. **A mountain centre:** the wall runs up to each column's surface, which may be up to 300 blocks. That is a one-off
   cost per realm (about 40 columns), accepted.
5. **Old realms.** Nothing changes for them. Only new realms are cased.

    /**
     * Whether a block in the casing fuses into aurora slate: anything solid that is not leaves, has no block entity (a
     * chest keeps its contents) and can be broken; a fluid only in the wall above the floor, where it is sealed in so it

    public static boolean fuses(boolean fluid, boolean solid, boolean leaves, boolean entity, boolean unbreakable, boolean wall) {

    }

```java
    /** Whether the block at pos fuses into aurora slate (LandingDais.fuses), read from the world. */
    private static boolean fuses(ServerLevel level, BlockPos pos, boolean wall) {
        BlockState s = level.getBlockState(pos);
        return LandingDais.fuses(!s.getFluidState().isEmpty(), s.isSolid(), s.is(BlockTags.LEAVES),
                level.getBlockEntity(pos) != null, s.getDestroySpeed(level, pos) < 0, wall);
    }
```
